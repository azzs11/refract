# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow SemVer.

## [Unreleased]

### Added — P6: verified translation and test generation
- **`refract translate`**: prints the pattern in each target flavour, re-parses it with the
  target's front-end and proves it equivalent under full match and search; each check is
  replayed on both real engines. Falls back to a full-match-only translation (tail `$` → text
  end) when no form preserves search, and says so. Constructs with no form are named with their
  location (ADR-0013).
- **Printer** (`refract_core::print`): target shorthands (`\w`, `\d`, `\s`, `\p{L}`, …) only where
  the target resolves them to a subset of the set; word boundaries over another engine's word
  set via look-around; look-behind width rules (Python fixed, Java bounded); back-references
  across JavaScript only when their group has surely matched.
- **`refract tests`**: cases covering every state and transition of the minimal DFA (sampled
  for back-references), labelled by the model, confirmed on the engine, emitted as pytest, Jest,
  JUnit 5, Go `testing` or JSON.
- Property tests: `tests/translation.rs` (50k), `tests/translation_engines.rs` (CPython + V8).

### Fixed
- Reference interpreter: an empty loop iteration keeps its captures in CPython and the JDK
  (`()?\1` matches `""`); found by the Java oracle property test.

### Deferred
- LexLint (plan P6) is deferred; it is outside the v0.5 scope (plan §3).

### Added — P5: ReDoS lab
- **`refract redos`**: per engine the predicted worst-case growth (linear, `O(n^k)`,
  exponential) with an attack string, the measured time curve, and confirmed / not confirmed /
  contradicted (ADR-0012, spec/redos.md). `--attack` replays any attack; `--no-measure` is static.
- **Static analysis** (`refract_core::redos`): backtracking NFA with ε-path multiplicities, EDA
  and IDA (chain degree), search retry loop, atomic/possessive never pivot; attacks whose
  every early start fails, checked on `Σ{0,k}·L·Σ*` automata.
- **Engine models**: Go/Rust linear; V8 with and without its linear fallback; the JDK loop memo
  (n × body cost), derived from Pattern.java and measured.
- **Oracle timing**: a `time` operation in all four runners; timeouts kill and restart a runner
  (named Docker containers).
- **Benchmark** (`bench/redos`): 65 patterns, Refract vs recheck 4.5.0 vs regexploit 1.0.0,
  ground truth measured on CPython 3.15.2, V8 14.6 and JDK 25 (`bench/results/redos.md`).
- Findings: JDK loop memo, V8 fallback coverage (docs/findings.md).

### Known limits (P5)
- Work before a late *successful* match (e.g. lazy `^[\s\S]*?\s*$`) is not predicted: attacks
  are built to fail. The benchmark lists it as Refract's one miss.


### Added — P4: the remaining limits
- **Look-ahead inside unbounded repetition** (e.g. `^(?:(?!ab).)*$`): least-fixed-point terms
  (`Re::Fix`/`Var`) in the derivative engine.
- **Atomic groups and possessive quantifiers**, exact for prefix-free bodies (ADR-0010).
- **Back-references and other non-regular constructs**: a backtracking reference interpreter with
  each engine's rules and a bounded comparison labelled "no difference up to length N"
  (ADR-0011); the interpreter is checked against all four engines.
- **JavaScript**: `\p{..}` from V8-measured tables, the `v` flag (set operations, `\q{}`), the `y`
  flag, and exact UTF-16 code-unit semantics without `u` (ADR-0007, revised).
- **Java**: `\p{..}` from JDK-generated tables (all block/script spellings); `hasSupplementary`
  and the code-unit search it implies; unit-wise base scan in `\b`.
- Findings: two JDK behaviours (docs/findings.md).


### Added — P3: four real engines, look-around, cross-engine command
- **Front-ends for Python `re`, JavaScript (V8, Annex B and `u`), Go `regexp` and Java
  `java.util.regex`**, each a port of the engine's own parser logic, with specs in
  `spec/flavours/`. Unicode tables generated by running each engine (`tools/`).
- **Exact look-around and assertions anywhere** (ADR-0008): continuation-passing lowering for
  look-ahead and anchors, a look-behind context in the derivative engine, per-engine word sets,
  Java's `$`/`(?m)^`/Mn-aware `\b` and its 32-bit look-behind windows.
- **`refract-oracle`**: JSON-lines harness and runners for CPython, Node/V8, Go and the JDK,
  native or in pinned Docker images (`oracle/`).
- **`refract refract`**: one pattern, every engine; per engine SAME (proven), DIFFERS (shortest
  witness, replayed on both real engines) or REJECTS (confirmed). `refract equiv` replays on all
  engines too.
- Analysis domains (ADR-0007): JS without `u` is analysed over BMP haystacks; comparisons use the
  common domain.
- Real-engine agreement suites per engine (`tests/*_oracle.rs`), look-behind engine properties,
  engine findings (`docs/findings.md`, a V8 mid-surrogate search behaviour). ADRs 0007–0009.

### Changed
- Rust: backreferences and look-around are syntax errors (the engine rejects them);
  "unsupported" now always means "valid but not analysed yet".
- ADR-0004 superseded by ADR-0008.

### Added — P0–P2
- **P0 — foundation.** Cargo workspace (`refract-core`, `refract-cli`), canonical Unicode
  character-set algebra, span-carrying errors, analysis budgets, Unicode data provider,
  flavour-independent IR, semantics profiles, and a hand-written Rust-flavour (`regex` 1.x)
  parser, differentially tested against `regex-syntax`. `refract parse`, `refract flavors`.
  cargo-fuzz target for the parser. Specs: `spec/ir.md`, `spec/flavours/rust.md`.
- **P1 — two automaton engines.** Lowering from IR to regular terms per operation (full match,
  search) with static anchor resolution; minterm alphabets; Thompson NFA + subset construction;
  symbolic Brzozowski derivatives with intersection and complement; Hopcroft and Brzozowski
  minimisation; canonical DFA forms. Double-construction and algebraic-law property tests.
  `refract dfa` (table or Graphviz).
- **P2 — equivalence and witnesses.** Product-automaton equivalence with the canonical shortest
  readable witness (lazy on derivatives, eager on Thompson DFAs); in-process real-engine replay for
  the Rust flavour with `confirmed` / `predicted` / `contradicted` labels; `refract equiv` with
  text and JSON output; golden CLI snapshots. Spec: `spec/witness.md`. ADRs 0001–0006.

### Fixed
- `[^]--]`: after a leading literal `]`, `--` is the difference operator, not two literal dashes
  (found by the real-engine language test).
