# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow SemVer.

## [Unreleased]

### Added — P3: four real engines, look-around, cross-engine command
- **Front-ends for Python `re`, JavaScript (V8, Annex B and `u`), Go `regexp` and Java
  `java.util.regex`**, each a port of the engine's own parser logic, with specs in
  `spec/flavours/`. Unicode tables generated by running each engine (`tools/`).
- **Exact look-around and assertions anywhere** (ADR-0008): continuation-passing lowering for
  look-ahead and anchors, a look-behind context in the derivative engine, per-engine word sets,
  Java's `$`/`(?m)^`/Mn-aware `\b` and its 32-bit look-behind windows.
- **`refract-oracle`**: JSON-lines harness and runners for CPython, Node/V8, Go and the JDK,
  native or in pinned Docker images (`oracle/`).
- **`refract refract`**: one pattern, every engine; per engine SAME (proven), DIFFERS (shortest
  witness, replayed on both real engines) or REJECTS (confirmed). `refract equiv` replays on all
  engines too.
- Analysis domains (ADR-0007): JS without `u` is analysed over BMP haystacks; comparisons use the
  common domain.
- Real-engine agreement suites per engine (`tests/*_oracle.rs`), look-behind engine properties,
  engine findings (`docs/findings.md`, a V8 mid-surrogate search behaviour). ADRs 0007–0009.

### Changed
- Rust: backreferences and look-around are syntax errors (the engine rejects them);
  "unsupported" now always means "valid but not analysed yet".
- ADR-0004 superseded by ADR-0008.

### Added — P0–P2
- **P0 — foundation.** Cargo workspace (`refract-core`, `refract-cli`), canonical Unicode
  character-set algebra, span-carrying errors, analysis budgets, Unicode data provider,
  flavour-independent IR, semantics profiles, and a hand-written Rust-flavour (`regex` 1.x)
  parser, differentially tested against `regex-syntax`. `refract parse`, `refract flavors`.
  cargo-fuzz target for the parser. Specs: `spec/ir.md`, `spec/flavours/rust.md`.
- **P1 — two automaton engines.** Lowering from IR to regular terms per operation (full match,
  search) with static anchor resolution; minterm alphabets; Thompson NFA + subset construction;
  symbolic Brzozowski derivatives with intersection and complement; Hopcroft and Brzozowski
  minimisation; canonical DFA forms. Double-construction and algebraic-law property tests.
  `refract dfa` (table or Graphviz).
- **P2 — equivalence and witnesses.** Product-automaton equivalence with the canonical shortest
  readable witness (lazy on derivatives, eager on Thompson DFAs); in-process real-engine replay for
  the Rust flavour with `confirmed` / `predicted` / `contradicted` labels; `refract equiv` with
  text and JSON output; golden CLI snapshots. Spec: `spec/witness.md`. ADRs 0001–0006.

### Fixed
- `[^]--]`: after a leading literal `]`, `--` is the difference operator, not two literal dashes
  (found by the real-engine language test).
